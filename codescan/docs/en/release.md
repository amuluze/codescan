# Release chain, signing and notarization (English)

The release certification chain mirrors the proven chain in the axiom repository: when credentials are missing it **degrades automatically** (ad-hoc unsigned build, updater configuration stripped) and the build still succeeds; with credentials present it performs Developer ID signing + hardened runtime + `notarytool` notarization + stapling + minisign-signed updater artifacts.

The [Chinese version of this document](../release.md) is the original; this file mirrors it.

## Chain

```
bump version (package.json / apps/desktop/package.json / tauri.conf.json)
  → push tag (v*)
  → .github/workflows/release.yml (macos-15, arm64 only):
      conditional secret mapping (injected only when non-empty)
      → scripts/ci-macos-credentials.sh (.p12 → temporary keychain / .p8 → file)
      → pnpm run build:dmg (generate-release-config + tauri sign-only build)
      → xcrun notarytool notarize the DMG (3 retries) + stapler staple/validate
      → scripts/release-signing-check.sh (signature acceptance)
      → scripts/generate-latest-json.mjs + gh release create --draft + asset upload
  → publish the draft release manually (the updater endpoint works after publish)
```

Local release: run `task build:dmg` from the repository root (it auto-sources `~/.codescan/release-credentials.env`); artifacts land in `codescan/target/aarch64-apple-darwin/release/bundle/` (not under `src-tauri`).

## Credential conventions

Local credentials file `~/.codescan/release-credentials.env` (mode 0600, never committed, optional — missing means degraded build):

| Purpose | Variable | Notes |
| --- | --- | --- |
| Signing identity | `APPLE_SIGNING_IDENTITY` | Must match `security find-identity -v -p codesigning`; CI auto-discovers it from the .p12 |
| Signing certificate (CI) | `APPLE_CERTIFICATE` + `APPLE_CERTIFICATE_PASSWORD` | base64 .p12; provided only as step-level env to `ci-macos-credentials.sh`, never in the build env (Tauri only checks "present", forwarding it would double-import) |
| Keychain password (CI) | `KEYCHAIN_PASSWORD` | Defaults to `codescan-ci` |
| Notarization (option A, recommended) | `APPLE_API_ISSUER` + `APPLE_API_KEY` (Key ID or .p8 path/content) + `APPLE_API_KEY_PATH` | App Store Connect API key; locally `ci-macos-credentials.sh` normalizes content/path into `APPLE_API_KEY_PATH` |
| Notarization (option B, fallback) | `APPLE_ID` + `APPLE_PASSWORD` (app-specific) + `APPLE_TEAM_ID` | |
| Updater signing | `TAURI_SIGNING_PRIVATE_KEY` (base64-wrapped single line) + `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | Key pair `~/.tauri/codescan-v1.key` (key ID `A74549A0F0FCE20C`); **rotating the key requires updating the pubkey in `tauri.release.conf.json`, otherwise older clients cannot verify updates** |

CI secrets (amuluze/codescan): `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_API_ISSUER`, `APPLE_API_KEY_ID`, `APPLE_API_KEY_P8`, `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.

## Updater (auto-update)

- Endpoint: `https://github.com/amuluze/codescan/releases/latest/download/latest.json` (static direct link; **works only after the draft release is published**).
- Artifacts: `Codescan.app.tar.gz` + `.sig` (produced by the bundler), renamed in CI to `Codescan_<v>_aarch64.app.tar.gz(.sig)`; `latest.json` is generated by `scripts/generate-latest-json.mjs` (the signature is the full `.sig` text).
- The updater plugin is only registered in `lib.rs` when `plugins.updater` exists in the generated configuration (injected by `generate-release-config.mjs` when credentials are present) — development builds stay unconfigured.
- Signature check: `tauri signer verify -k ~/.tauri/codescan-v1.key <tar.gz> <tar.gz.sig>`.

## Acceptance commands

```bash
# signature acceptance (fail-closed on the release chain; add --allow-adhoc for local debugging)
task release:signing-check -- target/aarch64-apple-darwin/release/bundle/macos/Codescan.app
# updater artifact verification (requires task build:dmg first)
cargo test -p codescan-desktop --test updater_signature -- --ignored --nocapture
# degraded path regression (a build without credentials must succeed and be ad-hoc, without updater artifacts)
HOME=$(mktemp -d) task build:dmg
```

## Troubleshooting

- **`A timestamp was expected but was not found` when signing the DMG**: the RFC 3161 timestamp service `timestamp.apple.com` is unreachable — use a system proxy; probe with `codesign --force --sign "$APPLE_SIGNING_IDENTITY" --timestamp <any signed object>`.
- **`codesign` hangs in a headless CI environment**: the temporary keychain lacks `set-key-partition-list` (already built into `ci-macos-credentials.sh`; do not remove it).
- **Notarization accepted but stapling fails**: fetching the receipt is an independent network interaction — just retry; the workflow retries notarytool and stapler three times each.
- **GHA injects empty strings for unset secrets**: the conditional mapping must check "non-empty", not "defined", otherwise the updater/signing steps activate with empty credentials and the build fails at the final signing step.
