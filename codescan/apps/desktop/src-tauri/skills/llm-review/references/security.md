# 安全检查表

按入口类型选择相关项，不做全量堆叠。

## 注入与解析

- SQL/NoSQL：字符串拼接、`raw`/`extra`/`RawSQL`、动态表名/排序字段；确认参数化是否覆盖当前值。
- 命令：`exec`/`system`/`spawn(shell)`、`sh -c`、`child_process.exec`；检查参数是否拼接、是否可注入选项。
- 模板与表达式：服务端模板拼接用户输入、`eval`/`Function`/动态 import、SpEL/OGNL/表达式引擎。
- 路径：`readFile`/`open`/`send_file`/`join` 拼接用户输入；检查规范化、前缀校验与符号链接。
- 反序列化：pickle、YAML `load`、Java 原生、PHP `unserialize`、多态 JSON；检查类型白名单。

## 身份与授权

- 每个出入口是否有一致的认证；是否存在只在前端隐藏的权限控制。
- 对象级授权：按请求 ID 读取/修改资源前是否校验归属、租户、角色；批量接口是否逐项校验。
- 令牌：JWT 是否验签、校验 `exp/aud/iss`、算法是否可降级；会话固定、注销失效、Cookie 标志。
- 权限提升：角色/配额/价格等字段是否可由请求体直接绑定（mass assignment）。

## 数据与网络

- 密钥/凭据硬编码、出现在日志或错误响应；密钥生命周期与最小权限。
- SSRF：用户可控 URL、重定向后二次校验、内网/元数据地址过滤；开放重定向。
- 上传：类型/大小/内容校验、存储位置、可执行权限、文件名路径穿越。
- 加密：密码哈希、随机数来源、IV/Nonce 唯一性、TLS 校验、常量时间比较、自制加密。

## 配置与供应链

- 调试模式、宽松 CORS、缺失安全头、默认口令、过宽文件权限。
- 依赖锁定、CI 权限、构建脚本与发布凭据；只报片段中可见的风险，不臆测外部服务。
