# 代码质量检查表

只报有实际后果的缺陷；风格偏好不进入建议。

## 错误处理

- 吞错/空 catch、错误被转成默认值继续执行、失败后仍提交部分状态。
- 错误信息泄漏内部路径、SQL、令牌；错误码与语义不一致（404/403/500 混用）。
- 重试无上限、无退避、对非幂等操作重试。

## 并发与资源

- 共享可变状态无同步；锁顺序不一致；在锁内做 I/O 或调用外部服务。
- 未关闭的文件/连接/游标；无界缓存、队列、并发任务；缺少超时。
- 阻塞调用出现在异步执行器/事件循环；后台任务未处理 panic/取消。

## 可维护性

- 死代码、不可达分支、复制粘贴导致的不一致；隐式全局状态与顺序依赖。
- 资源所有权不清、生命周期交叉；同一语义多处实现且已分叉。
- 仅当缺陷会导致错误行为、资源泄漏或后续高风险改动时才报告；纯命名/格式问题不报。
