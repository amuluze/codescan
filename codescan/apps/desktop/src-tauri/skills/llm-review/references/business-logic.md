# 业务逻辑检查表

业务逻辑问题必须落到具体不变量与状态迁移，不能只写“缺少校验”。

## 归属与隔离

- 读取/更新/删除是否同时校验资源归属与当前身份；是否只校验资源存在。
- 列表、导出、搜索、批量操作是否按租户/用户过滤；缓存键是否带隔离维度。
- 后台任务、回调、Webhook 是否携带并校验租户上下文。

## 状态与金额

- 状态机：是否允许跳过步骤、回退、重放；取消/退款/审批是否有终态保护。
- 金额/库存/配额：计算是否使用可信来源、是否可被请求体覆盖、是否处理并发扣减与舍入。
- 幂等：重复提交、重试、消息重投是否产生二次副作用；幂等键作用域是否正确。
- 事务：多表/多存储写入是否原子；部分失败是否留下不一致状态；是否先写后校验。

## 并发与时间

- check-then-act 是否有锁、唯一约束或原子操作；竞态窗口是否可利用。
- 过期、配额重置、签名时间窗是否使用服务端时间；是否存在 TOCTOU。
- 异步任务是否可能乱序、重复或丢失，失败是否可恢复。
