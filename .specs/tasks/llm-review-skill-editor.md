# Task Spec：内置 Skill 查看与编辑

task-id: `llm-review-skill-editor`

## 目标

在设置页新增「LLM 审查内置 Skill」卡片：查看随应用分发的技能文件，按文件编辑并保存本地覆写，或恢复内置默认。审查与复核在运行期优先使用覆写内容；注入边界、JSON 输出契约与「不参与门禁」约束仍由代码固定，不可经覆写修改。

## 现状（证据）

- 技能包经 `include_str!` 编入 `llm.rs`，`REVIEW_SKILL_FILES` 为唯一内容源；运行期没有覆写读取路径。
- 设置页只有 Provider、应用更新、安全边界三张卡；没有 `llm_review_skill_*` 命令。
- Axiom 的参考实现是「内置条目列表 + 编辑弹窗 + 已自定义标记 + 恢复默认 + 超长拒绝」，持久化与运行时读取分离。

## 范围

1. **技能文件模型**
   - `llm.rs` 暴露 6 个内置文件（名称/用途/正文）与 `ReviewSkillOverrides`；提供按名替换、清除、是否自定义、总字节数。
   - 名称必须命中内置清单；正文不得为空白；单文件 ≤16 KiB，覆写合计 ≤32 KiB；超限与非法名称返回可读错误。
   - 提示词改为运行期组合：代码固定的注入边界、版本标记、输出契约 + 当前生效技能正文。
2. **持久化（Rust 独占）**
   - 覆写写入 `~/.codescan/skills/llm-review.json`（`version` + 文件名 → 正文）。
   - 读取时逐项校验，损坏/超限/未知名称的条目跳过并回落内置；写入使用临时文件 + rename。
   - 保存内容与内置正文一致时视为移除覆写；全部清空时删除覆写文件。
3. **命令**
   - `llm_review_skill_info`：版本、文件列表（名称/用途/生效正文/是否覆写/字节数）、限制。
   - `save_llm_review_skill(name, content)` 与 `reset_llm_review_skill(name)`：返回更新后的单条信息。
   - `llm_review_workspace` 在调用前读取覆写并传给猎取/复核提示词。
4. **设置页**
   - 新增「LLM 审查内置 Skill」卡：版本、限制说明、文件表（文件/用途/大小/状态/操作）。
   - 「查看 / 编辑」打开弹窗：等宽 textarea、字节计数、保存、恢复默认（仅覆写项可用）、取消；空白/超限禁用保存并说明原因。
   - 保存/恢复后就地更新列表与「已覆写」标记；失败以 `role="alert"` 展示，不关闭弹窗。
5. **边界与文档**
   - 覆写不改变：源码不可信声明、输出 JSON 字段与校验、复核判定枚举、建议不写 findings/基线/门禁。
   - 同步 Domain §3b、`docs/llm.md`、`docs/en/llm.md`、`DESIGN.md`、README、CHANGELOG。

## 验收标准

- [ ] Rust 单测：提示词使用覆写正文；注入边界、版本标记与 JSON 契约仍在；未知名称、空白、单文件超限、总量超限被拒绝。
- [ ] Rust 无头测试：以临时数据根保存 → 读取生效 → 恢复默认删除覆写 → 文件与内容与内置一致；损坏 JSON 回落内置。
- [ ] Rust 无头测试：与内置正文相同的保存不产生覆写文件；全部恢复后覆写文件被删除。
- [ ] 前端测试：设置页加载文件列表与「内置」状态；打开编辑弹窗、修改并保存调用命令且更新「已覆写」；恢复默认调用命令。
- [ ] 前端测试：空白正文禁用保存；命令失败在弹窗内展示错误且不关闭。
- [ ] 运行期：覆写后 `review_system_prompt_with` 含新正文；`llm_review_workspace` 读取同一存储（代码路径引用，无第二份实现）。
- [ ] 文档与 Domain 同步；覆写文件不写入工作区。

## 排除项

- 不做多语言版本、项目级 Skill 目录、外部 SKILL.md 安装或联网更新。
- 不提供覆写历史/版本回滚；恢复默认即回到当前内置版本。
- 不改变复核开关、分页、预算与建议展示语义。
