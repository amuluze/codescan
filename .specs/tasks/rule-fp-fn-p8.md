# Task Spec：跨函数对象身份等价

task-id: `rule-fp-fn-p8`

## 背景

字段写效果能让调用方看到 `fill(o, v)` 的写入，但返回值与实参的对象身份没有关联：

```ts
function id(o) { return o; }
const b = id(a);
b.value = input;
eval(a.value); // 之前漏报
```

## 范围

- 函数摘要新增返回值对象身份：返回形参、形参字段或局部别名时，记录目标形参索引与字段路径。
- 调用点仅在右侧恰为调用表达式时，将左值对象集合与实参对象（或字段对象）合并。
- 支持嵌套字段返回：`return o.inner`。
- 对象字面量/克隆返回不视为身份等价：`return { ...o }` 不建立别名。
- 修正 return 事实只保存返回表达式，避免把 `return` 语句结构误判为对象路径。

## 验收

- [x] `id(a); b.value = input; eval(a.value)` 命中。
- [x] `inner(a)` 返回字段对象后写入，调用方原字段读取命中。
- [x] 对象克隆返回不建立身份等价。
- [x] 身份与字段写效果组合命中。
- [x] taint 单测、规则 fixture、全量门禁通过。

## 排除项

- 完整跨过程堆图/形状摘要。
- 条件/联合返回对象的精确身份集合。
- 通过容器元素或数组索引逃逸的对象身份。
