# Task Spec：条件值裁剪对象身份

task-id: `rule-fp-fn-p10`

## 背景

条件/联合返回当前取所有值分支的身份并集；当条件值静态可知时会引入不存在的身份：

```ts
function choose(a, b) { return true ? a : b; } // 只应返回 a
```

## 范围

- 三元表达式条件可判定时只收集选中分支：
  - `true` / `false`
  - 括号、`!` 取反
  - 数字 0/非 0、字符串空/非空、对象/数组字面量
- 逻辑/空值联合：
  - `||` 左侧真值时取左，假值时取右。
  - `??` 左侧可判定 null/undefined 时取右，可判定非空时取左。
  - 未知时保持双分支并集。
- 条件参数等未知值不误裁剪。

## 验收

- [x] `true ? a : b` 只关联 `a`。
- [x] `false ? a : b` 只关联 `b`。
- [x] `null ?? b` 只关联 `b`。
- [x] 未知 `flag ? a : b` 仍关联两分支。
- [x] 规则 fixture、taint 单测与全量门禁通过。

## 排除项

- 基于变量赋值的数据流常量传播（如 `const flag = true`）。
- if/else 控制流合并与路径敏感求解。
