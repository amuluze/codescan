# Task Spec：Codescan v5 —— 跨文件污点 + 字段/堆别名近似

task-id: `codescan-taint-v5`

## 目标与边界

Domain §4b：同语言显式导入跨文件（TS/JS/TSX/JSX、Python、Go 同包）；字段敏感访问路径；对象组别名近似。Java/Rust 跨文件、全量 points-to、形状敏感为排除项。v4 全部语义与 fixtures 零回归。

## 范围

### A. 跨文件（IR + 项目级分析）

- 每（污点规则, 文件）提取事实 IR：函数（名/形参/局部 source/sink 范围与文本/赋值序列/返回表达式/调用点含实参表达式）+ 导入表（本地名 → 目标模块与导出名；Go 同目录隐式同包）。
- 事实需可序列化于内存结构，不保留语法树；模块 id = 工作区相对路径去扩展名（Go 为目录）。
- 项目分析：解析调用名（本地优先，其次显式导入；未解析不跨文件），复用布尔摘要不动点（全局函数 id），跨文件收集 sink，flows 合并；同 sink 去重。
- 确定性：文件与函数顺序按路径/字节序；结果双跑字节一致。

### B. 字段敏感 + 堆别名近似

- 表达式/赋值采用访问路径（base + 字段链）；对象字面量按字面键展开（TS/JS/Python）；索引访问通配；读取整对象匹配其字段污点。
- 对象组：`a = b` 标识符别名加入同组；组内字段写入共享；重新赋值强更新；组记录首个源头位置。
- sanitizer 语义沿用（表达式覆盖/标识符范围）。

## 验收标准（可客观判定）

- **F1 跨文件调用链**：TS 双文件（`a.ts` 导入 `b.ts` 的 `run`，`eval` 在 b）→ 命中，flows 含 a 的源头；Python 双文件同断言。
- **F2 Go 同包**：同目录两文件，一文件 source → 另一文件 sink → 命中；不同目录同名 → 不命中。
- **F3 未导入同名不跨文件**：无 import 的同名函数 → 不产生跨文件流（负例）。
- **F4 字段敏感**：`obj.a = tainted; sink(obj.b)` 不命中；`sink(obj.a)` 命中；对象字面量 `{a: tainted}` 同理。
- **F5 堆别名**：`alias = obj; alias.a = tainted; sink(obj.a)` 命中；`alias = {}; alias.a = tainted; sink(obj.a)` 不命中（重赋值强更新）。
- **F6 零回归**：v4 全部 fixtures/单测/集成绿；新增跨文件 fixture 仅 v5 可命中。
- **F7 确定性/性能**：双跑一致；1000 文件 A9 语料 ≤ 90s。

## 失败语义

- 导入解析失败/目标缺失：该调用保守视为未解析（不跨文件），不报错。
- IR 提取遇到语法错误：沿用 degraded 语义（该文件命中标记 degraded）。

## 排除项

Java/Rust 跨文件；全量 points-to 与形状/路径敏感；跨文件堆别名；动态导入/反射/字符串调用。

## 结论（2026-11-09，已实施）

引擎重构为「事实 IR 提取（`taint/facts.rs`）+ 项目级分析（`taint/engine.rs`）」：每（规则, 文件）提取函数事实（形参/参数源标记/语句序列含赋值与对象字面量/返回表达式/调用与实参）与导入表，不保留语法树；项目分析先构建 (module, name) 索引与每文件解析表（本地 → 显式导入 → Go 同包），再做摘要不动点（形参→sink / 返回值→形参 / 返回值内部污点）与调用链收集。字段/对象组状态：访问路径 + 对象字面量按键展开 + 索引通配 + `a = b` 组别名与强更新。

验收：F1 TS 跨文件（flows 含调用者参数位）与 Python 跨文件；F2 Go 同包跨文件；F3 无导入同名不跨文件（负例）；F4 字段敏感（`obj.a`/`obj.b`、字面量 `box.a`/`box.b`）；F5 别名写透传与重赋值强更新；F6 全量规则套件（含既有 17 条污点 fixtures）与单测（37）/集成（10）全绿；F7 双跑一致、sanitizer 仍生效。实现中修复三处结构缺陷：赋值型 sink 被赋值分支吞掉、Go `selector_expression` 被调名缺失、未知被调时实参未求值。实测 axiom：734 发现 / 37s（debug CLI，1015 文件），较 v4 少 1 条（字段敏感去噪）。
