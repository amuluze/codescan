# Task Spec：Codescan v6 —— Points-to 对象集合 + 形状敏感

task-id: `codescan-taint-v6`

## 目标与边界

把 v5 的「变量→单对象组 + 扁平字段串」升级为（Domain §4b）：
- **points-to 集合**：变量持有对象集合；赋值/别名合并集合；新分配创建对象。
- **形状/字段指针**：对象字面量递归展开为字段路径；对象字段可指向其它对象（字段指针集合），读取沿堆图解析。
- **强更新**：字段写入对集合内对象的字段（含子路径）强更新；通配索引读写按 `*` 字段处理；数组元素按通配。
- 边界：跨过程仅值摘要，**无跨过程堆摘要**；路径敏感合并不做；Rust/Java 等语言的对象字面量缺失处退化为「新对象 + 整体污点」。

## 验收标准

- **P1 嵌套形状**：`box = {a: {b: read()}}; eval(box.a.b)` 命中；`eval(box.a.c)` 不命中；`eval(box.b)` 不命中。
- **P2 嵌套写入**：`obj.a.b = read(); eval(obj.a.b)` 命中；`eval(obj.a.c)` 不命中。
- **P3 字段指针别名**：`base = {}; box = {x: base}; box.x.f = read(); eval(base.f)` 命中；`eval(box.y)` 不命中。
- **P4 集合合并/强更新**：`a = {}; b = {}; c = a; c.f = read(); eval(a.f)` 命中、`eval(b.f)` 不命中；`c = {}` 后写入仅对 c 新对象可见（`eval(a.f)` 不复命中）。
- **P5 通配索引**：`obj[k] = read(); eval(obj.any)` 命中（不足取精度）；`obj.known = read(); eval(obj[k])` 命中。
- **P6 零回归/确定性/性能**：v5.2 全部测试（42 单测/10 集成/规则套件/CLI）绿；双跑一致；axiom 扫描 ≤ 90s。
- **P7 数组**：`const arr = [read()]; eval(arr[0])` 命中；`eval(arr)` 命中（整体含污点）。

## 失败语义

- 无法解析的字段（非标识符键/计算属性）：按通配 `*` 处理（保守）。
- 无对象字面量的语言：赋值仅创建新对象并记录整体污点（形状退化）。

## 排除项

跨过程堆摘要、路径敏感（分支合并）、全堆等价与循环堆精化、Java/Rust 构造器内部字段（保守整体）。

## 结论（2026-11-09，已实施）

污点状态替换为 PointsToState：变量 → 抽象对象集合（points-to），对象 → 字段 →（字段指针集合，字段污点），对象整体污点；对象/数组字面量在事实层递归展开（数组元素并入 `*` 通配字段），形状初始化创建嵌套子对象；字段写入对集合内对象强更新（含子路径清理）；读取沿堆图逐段解析（字段指针 + 前缀匹配 + 通配 `*` 双向匹配），整对象读取递归聚合可达污点。

验收：P1 嵌套形状读（仅 box.a.b 命中）；P2 嵌套写（仅 obj.a.b）；P3 字段指针别名（`{x: base}` 写入经 base.f 可见）；P4 集合合并（c=a 写命中 a.f 不命中 b.f）与重赋值强更新（a.f 不复命中）；P5 通配索引双向；P7 数组元素与整体读取；P6 零回归（污点单测 27、引擎 48、集成 10、规则套件、CLI 12 全绿；clippy 0）与确定性/性能（axiom 1015 文件 734 发现 38.6s）。实现中修复通配读语义（`obj[*]` 需匹配任意字段）与字面量字段键解析。
